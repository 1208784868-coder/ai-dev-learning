# AI 辅助开发学习记录

这是我在学习如何通过 AI 辅助完成软件开发时创建的练习仓库。

## 学习目标

- 理解 Git 和 GitHub 的基本概念
- 熟悉仓库、提交、分支和 Pull Request
- 学会向 AI 清楚描述开发任务
- 学会检查 AI 修改的代码
- 完成一个可以运行的小项目

## 学习记录

- 2026-11-25：创建第一个仓库

## 协作流程

1. 用 Issue 写清目标和完成标准。
2. 从 main 创建独立分支。
3. 按小步骤修改并提交。
4. 发起 Pull Request 说明改动和验证结果。
5. 等待自动检查和人工审查。
6. 检查通过后合并到 main。

## 本地开发环境

项目已克隆到本地电脑，可以使用 Visual Studio Code 编辑，并通过 Live Preview 预览页面。
